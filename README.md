# Awesome SolidCraft Plugins

A curated collection of plugins, extensions, and community tools for [SolidCraft CAD](https://github.com/tangency-labs/solidcraft).

Discover useful plugins, explore new features, and share your own projects.

## Plugins

- [Gridfinity Generator](https://github.com/Xusr404/solidcraft-gridfinity-generator) - Generate customizable Gridfinity storage bins and baseplates in SolidCraft.
- [Honeycomb / Hexagon Generator](https://github.com/Xusr404/solidcraft-honeycomb-plugin) — Fill one or more sketch regions with a continuous hexagon pattern. Adjust the cell size and spacing, and optionally trim cells at the outline.
- [SolidCraft Gears](https://github.com/bherbruck/solidcraft-gears) - Generate involute spur gears by specifying the module, tooth count, and face width. The gear is built with editable SolidCraft timeline features.
